# Dítě Záznam

Jednoduchá Flask aplikace pro záznam kojení (množství mléka, stolice, moč, zvracení) s přehledem a možností mazání záznamů.

Kterou nejspíš nikdo kromě mne nikdy nevyužije.

## Spuštění

```bash
./start.sh
```

Aplikace poběží na `http://localhost:5000`.
